# 시연(전시)용 데이터

전시·발표에서 앱을 보여주기 위한 준비 자료예요.

- **구장은 공공데이터의 실제 풋살장 10곳을 넣어요.** 국민체육진흥공단 "전국체육시설 정보"에서 정상운영 중인 풋살장 중 **서울 중랑구청에서 가까운 10곳**을 골라 이름·주소·위치·실내외를 그대로 넣어요.
  - 사진·편의시설·요금·운영시간은 팀이 직접 확인한 실제 정보로 **앱의 "구장 관리"** 에서 채워요 (아래 1-2).
  - 앱에서 날짜·시간 선택 → 토스 결제 → 예약 확정 → 취소·환불까지 실제로 동작해요 (토스 테스트 키라 돈은 안 나가요).
- **SNS(영상·게시물)는 팀원이 직접 만들어요.** 실제 계정으로 영상을 올리면 업로드·변환·재생까지 실제로 동작해요.

## 1. 실제 풋살장 10곳 넣기 (공공데이터)

**준비:** 공공데이터포털에서 "국민체육진흥공단_전국체육시설 정보" 활용신청 → 승인되면 마이페이지에 **일반 인증키**가 보여요.

`C:\dev\fmate` 에서 PowerShell로 (서버가 켜져 있어야 해요). **운영자 계정을 먼저 만들어 두면** 10곳이 그 계정에 바로 연결돼요:

```
docker compose cp backend/demo/demo_seed.sql db:/tmp/demo_seed.sql
docker compose exec db psql -U fmate -d fmate -f /tmp/demo_seed.sql
docker run --rm -e DATA_GO_KR_KEY="여기에인증키" -v "C:\dev\fmate\backend\demo:/work" python:3.12-slim python -u /work/import_public_futsal.py
docker compose cp backend/demo/public_futsal.sql db:/tmp/public_futsal.sql
docker compose exec db psql -U fmate -d fmate -f /tmp/public_futsal.sql
```

- 전국 체육시설 15만여 곳을 훑느라 **몇 분** 걸려요. 끝나면 고른 10곳과 거리가 표시돼요.
- 마지막에 `COMMIT` 이 나오면 끝이에요. **예전에 넣은 전국 풋살장(800여 곳)은 이때 지워지고** 10곳만 남아요.
- 기준점이나 개수를 바꾸려면 `docker run` 에 `-e LIMIT=12` · `-e CENTER_LAT=37.59 -e CENTER_LNG=127.08` 를 추가해요.
- **다시 실행해도 안전해요.** 이미 들어 있는 같은 구장은 그대로 두므로 올린 사진·수정한 요금이 지워지지 않아요. 목록에서 빠진 구장만 지워요.
- 앱의 구장 상세 맨 아래에 공공데이터 출처가 작게 표시돼요 (공공누리 출처 표시).

### 1-2. 사진·편의시설·요금 넣기 (앱에서)

1. 사진을 에뮬레이터 화면에 끌어다 놓아 갤러리에 넣어요 (실제 폰이면 그냥 촬영).
2. 앱에서 `owner@fmate.demo` / `demo1234` 로 로그인 → **마이 → 구장 관리** → 구장 선택
3. **정보** 탭: 사진 추가(첫 장이 대표 사진) · 편의시설 선택 · 전화번호 · 소개 · 이용 규칙 → 저장
4. **코트** 탭: 코트 이름·실내외·크기 수정, 코트 추가 / **운영시간·요금** 에서 실제 요금으로 바꾸기
5. 다시 일반 계정으로 로그인하면 구장 목록·상세에 바로 반영돼요.

### 운영자·관리자 계정

위 1번의 `demo_seed.sql` 이 만들어요: `owner@fmate.demo` (구장 운영자), `admin@fmate.demo` (관리자), 비밀번호 모두 `demo1234`.

## 2. 팀 계정 만들고 영상 올리기 (앱에서 직접)

팀원 3~4명이 각자 계정을 만들어요.

1. 앱 → **회원가입** (이메일, 비밀번호, 닉네임, 약관 동의)
2. 프로필 설정 (소개, 지역, 포지션). 프로필 사진도 올릴 수 있어요
3. **이메일 인증** — 영상을 올리려면 필요해요. 인증 코드는:
   - PC 서버: http://localhost:8025 (Mailpit)에서 확인
   - 클라우드 서버: 메일 발송을 설정했으면 실제 메일함으로 와요
4. **영상 올리기** — 아래 탭 가운데 **＋** → 영상 → 설명·해시태그·**구장 태그** → 올리기
   - **90초 이하**, 500MB 이하, mp4 또는 mov
   - **세로 영상**이 숏폼 화면에서 가장 보기 좋아요
   - 올린 뒤 1~2분 지나면 "처리 중"에서 재생 가능 상태로 바뀌어요 (서버가 스트리밍용으로 변환)
5. 사진 게시물도 섞고, **구장 태그를 꼭 붙이세요** — 홈 영상에 "구장 · 오늘 남은 시간 · 예약" 카드가 붙고, 구장 상세의 "이 구장에서 올라온 영상"에 모여요
6. 팀 계정끼리 서로 **팔로우**, 좋아요, 댓글을 몇 개 남겨 두세요

**에뮬레이터에서 영상 올리기:** 영상 파일을 에뮬레이터 화면에 **끌어다 놓으면(drag & drop)** 에뮬레이터의 다운로드 폴더에 들어가요. 그다음 앱에서 영상을 고를 때 그 파일을 선택하면 돼요. 실제 휴대폰이 있으면 갤러리에서 바로 고르면 되니 더 편해요.

**사용할 영상:** 팀원이 직접 찍은 영상만 쓰세요. 인터넷에서 받은 경기 영상이나 음악이 들어간 영상은 저작권 문제가 생길 수 있어요.

## 3. 관람객 체험 순서 (에뮬레이터 2대를 나란히)

1. **홈** — 앱을 열면 팀이 올린 영상이 전체 화면으로 재생돼요. 위로 넘기면 다음 영상
2. **영상 → 예약** — 영상 아래 구장 카드의 **예약** → 구장 상세 → 시간 2칸 선택 → 아래 **예약하기**
3. **결제** (토스 테스트 키를 넣은 경우) — 토스 결제창 → 예약 확정 → 마이의 "다가오는 경기" → 취소 → 환불
   - 예약은 이메일 인증이 필요하니 **미리 인증해 둔 팀 계정**으로 로그인해 두세요
4. **좋아요·댓글·팔로우** — 왼쪽 화면에서 누르면 오른쪽 화면(작성자 계정) 아래에 몇 초 안에 알림이 떠요
5. **채팅** — 프로필 → 메시지 → 상대 화면에서 실시간 수신
6. **중복 예약 방지** — 두 화면에서 같은 시간을 동시에 예약하면 한쪽만 성공하고, 다른 쪽엔 "방금 다른 분이 먼저 예약했어요"
7. **구장 찾기** — 구장 탭에서 날짜·시간대·실내·샤워실 칩으로 거르기

시연에서 새로 만든 계정은 전시가 끝난 뒤 관리자 화면에서 정리하거나 그대로 둬도 돼요.

## 4. 지우기

| 무엇을 | 파일 |
|---|---|
| 공공데이터 구장에 잡힌 예약·결제만 (구장·사진은 그대로) | `bookings_reset.sql` |
| 공공데이터 구장 + 그 구장의 예약·결제 (사진도 함께 지워짐) | `public_futsal_reset.sql` |
| 시연 계정(`@fmate.demo`) | `demo_reset.sql` |

```
docker compose cp backend/demo/public_futsal_reset.sql db:/tmp/r.sql
docker compose exec db psql -U fmate -d fmate -f /tmp/r.sql
```

- **팀원이 만든 계정과 영상·게시물은 지우지 않아요.**
- 전시 전날·전시 중 쉬는 시간에 `bookings_reset.sql` 을 실행하면 관람객이 잡은 예약이 사라져 시간표가 다시 비어요.

## 주의

- `@fmate.demo` 계정 비밀번호는 공개된 값(`demo1234`)이니, 실제 서비스 서버에는 이 데이터를 넣지 마세요.
- 관리자 계정으로 승인·제재 같은 작업을 하면 그 기록(감사 로그)은 설계상 지울 수 없어서, 지우기를 해도 관리자 계정은 남아요. 다시 넣기를 하면 남은 계정을 그대로 써요.
